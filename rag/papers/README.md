# rag/papers

RAG 지식베이스를 만들 때 사용한 HTP 그림검사 관련 학술 논문 PDF를 두는 폴더입니다.
저작권 문제로 논문 원문은 저장소에 포함하지 않았습니다.

| 논문 | 추출 지표 수 |
|------|------------:|
| 모바일 기반 HTP그림검사 앱 개발을 위한 표준화 연구 (손성희, 2015) | 600 |
| HTP(House-Tree-Person) 검사 해석체계 구축 및 타당성 제고 | 591 |
| 어린이의 HTP 검사 반응에 대한 해석과 특징연구 | 552 |
| 인공지능 객체검출모델 기반 집-나무-사람(HTP) 그림검사의 형식적 해석 연구 | 75 |
| 아동의 동적 집-나무-사람(H-T-P) 그림 반응 특성과 우울과의 관계 | 33 |
| 집-나무-사람 그림검사(HTP) | 0 |

- 논문에서 추출한 지표 1,851건은 `rag/dataset/htp_final_dataset.json` 에, 이를 임베딩한 벡터 DB는 `rag/chroma/` 에 포함되어 있어 **논문 없이도 서비스는 바로 동작**합니다.
- 지표를 새로 추출하려면 각 논문을 학술 DB(RISS, KCI 등)에서 받아 이 폴더에 넣고 `rag/scripts/htp_indicator_parser.py` 를 실행하세요.
