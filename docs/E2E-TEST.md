## 상세

### RAG 검색 결과 (실제 응답)

```
쿼리: "나무 기둥이 가늘고 위축된 느낌"
 1) 작고 외소한 나무 기둥에 외상의 흔적이 많음
    → 무기력하며 위축되어 있고 내면에 우울한 상태가 많이 잠재
    (어린이의 HTP 검사 반응에 대한 해석과 특징연구.pdf)
 2) 잎에 비해 기둥이 크고 넓게 그림
    → 성격 구조가 약하고 부족하지만 불안감 해소를 위한 과장 표현
    (어린이의 HTP 검사 반응에 대한 해석과 특징연구.pdf)
 3) 크기 비율 33% 이하
    → 열등감·무력감 시사
    (인공지능 객체검출모델 기반 집-나무-사람(HTP) 그림검사의 형식적 해석 연구.pdf)
```

### /analyze 실제 응답 요약

```
STATUS 200  (56.3s)
child            : {name: 테스트, age: 7, gender: 남}
results          : tree / house / man / woman 각각
                   인상적_해석, 구조적_해석, 표상적_해석, 정서_영역_소견,
                   추천_사항, source(참고 논문)  + box_image_base64
comparison       : peer, development, psychology, overall_score(41.2),
                   drawing_scores{에너지 47.5 / 위치안정성 48.3 / 표현력 27.8}
recommendations  : 3 카테고리 × 8건
전체_심리_결과    : 종합/인상적/구조적/표상적 + 긍정적인_측면 + 주의_사항
activity_recommendations : 활동 3건 + 신호 5건 + 안내 문구   ← iSeed 신규
```

> `source` 필드는 RAG 적재 **이후**에 나타났습니다.
> 적재 전 동일 이미지로 돌린 응답에는 `source` 와 `추천_사항` 이 없었으므로,
> RAG가 실제로 해석에 반영되고 있음을 확인할 수 있습니다.

### 수정한 버그

| 버그 | 증상 | 수정 |
|------|------|------|
| 호흡 게임 타이머 단계 불일치 | 들이마시기/멈추기/내쉬기 라벨과 카운트다운이 어긋남 (stale closure) | 단일 상태 객체 + 단일 타이머로 재작성 |
| 임베딩 모델 제공 중단 | `models/embedding-001` 404 → RAG 색인·검색 모두 실패 | `RAG_EMBEDDING_MODEL` 도입, 현행 모델로 교체 |
| HNSW 인덱스 미flush | 벡터 1,851건이 있어도 검색이 조용히 0건 | `init_rag.py` 자가 복구 + `/rag/status` 에 `index_ok` 추가 |

## 샘플 산출물

실제 분석 1회분(입력 이미지 4장, YOLO 박스 이미지 4장, 구성요소 JSON, 그림별 해석 JSON, 전체결과 JSON)은
입력 그림이 AI 허브 데이터라 공개 저장소에는 포함하지 않았습니다.

### 챗봇 (`POST /chatbot`)

| 챗봇 | 질문 | 결과 |
|------|------|------|
| 가이드 | 그림은 몇 장 올려야 해요? | ✅ 5.7~9.7초, "4장, 나무·집·남자사람·여자사람" + 업로드 방법 |
| 가이드 | 마음 씨앗은 어떻게 키우나요? | ✅ 리포트 확인 시 생성 → 마음활동으로 포인트 → 단계 성장 |
| 가이드 | 그림일기 사진을 글자로 바꾸고 싶어요 | ✅ "현재 제공하지 않습니다" (OCR 삭제 반영) |
| 가이드 | 결과를 PDF로 저장하려면? | ✅ 리포트 오른쪽 위 `PDF 저장` + 진단 아님 안내 |
| 후속 질문 | 나무 그림에서 어떤 점이 눈에 띄었나요? | ✅ 실제 해석 내용("기둥의 과장된 표현")을 근거로 설명 |
| 후속 질문 | 표현력 점수가 낮은데 우리 아이는 말을 잘해요 | ✅ 그림 표현력 ≠ 언어 능력, 검사 시점 차이 설명 |
| 후속 질문 | 집에서 뭘 해주면 좋을까요? | ✅ 추천된 마음활동 3개를 가정 활동으로 안내 |

- 후속 질문 챗봇에 전달되는 분석 정보: 수정 전 4개 필드(그림별 해석 0/4) → 수정 후 약 2,000자(그림별 해석 4/4)
- 모든 답변에서 진단·단정 표현 없음

### 남은 사항
- 기본 모델 `gemini-3.5-flash-lite` 로는 과부하(503) 때문에 전체 검증을 하지 못함.
  현재 `.env` 의 `GEMINI_MODEL=gemini-3.1-flash-lite` 로 검증 완료. 줄을 지우면 기본값으로 돌아갑니다.
- 무료 한도는 프로젝트 단위. 시연 전 결제 연결 권장.
